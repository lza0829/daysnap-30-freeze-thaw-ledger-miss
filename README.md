# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |
| 回放核对 | 前日快照+当日流水 vs 当日快照 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |
| 冻结流水 | 负余额闸拟负笔（不计正式净额，按流水号可查） |

## 负余额闸（冻结流水轨 · 已落地）

台参 `禁止负余额=开` 启用（默认关，主链冒烟行为不变）。全局唯一架构为**冻结流水轨**，与「直拒旁置」口径的可区分点：拟负笔不入 `变动流水`（按流水号查正式流水为空），写入 `冻结流水` 轨（按流水号可查冻结行），正式净额不变。

- **同源**：拟负判定、装载冻结写、抽取跳过、回放净额共用同一口径——有效开端（前日有效镜，无则零）+ 当日正式净额（仅 `变动流水` 且命运=已入账，冻结轨永不参与）。
- **装载**：逐笔拟算，拟负写冻结轨并留闸决策；写事务 `BEGIN IMMEDIATE` 串行化，双出账交错失败闭。
- **抽取**：同源拟算，拟负拒写有效镜（旧有效镜置失效），报告含 `闸拒`。
- **解冻** `POST /api/负余额闸/解冻`：重新拟算，过闸才入正式流水并可抽；仍负保持冻结（失败闭）。冻结期间同号重装撞冻结轨 → 旁置；须解冻或换号重装。
- **核证** `GET /api/负余额闸/核证?流水号=`（或 `账户键&营业日`）：拟余额、路径、冻结有无、valid 四要素，附正式流水/冻结行命中。
- 另：`GET /负余额闸/冻结`、`GET /负余额闸/决策`、`POST /负余额闸/开关`。
- 测试：`cd backend && pytest`（12 项，含拟负夹具、双出账并发、解冻、旧库升级、HTTP 端到端）。
